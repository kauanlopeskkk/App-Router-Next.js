# Lista de Tarefas

Aplicacao de lista de tarefas criada com Next.js App Router, React e TypeScript. O projeto permite listar tarefas iniciais, adicionar novas tarefas, marcar itens como concluidos e remover tarefas da lista.

## Tecnologias

- Next.js
- React
- TypeScript
- Jest
- Testing Library

## Instalacao

Instale as dependencias dentro da pasta do app:

```bash
cd my-app
npm install
```

## Execucao

Rode o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```

## Testes

Execute a suite de testes:

```bash
npm test
```

Para desenvolvimento com testes em modo observacao:

```bash
npm run test:watch
```

## Scripts

- `npm run dev`: inicia o ambiente de desenvolvimento.
- `npm run build`: gera a build de producao.
- `npm run start`: executa a build de producao.
- `npm run lint`: executa o ESLint.
- `npm test`: executa os testes automatizados.
