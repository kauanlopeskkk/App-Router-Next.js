# App-Router Next.js

Repositorio com uma aplicacao de lista de tarefas em Next.js App Router.

## Estrutura

- `my-app/`: codigo fonte do projeto, configuracoes, testes e README completo.

## Como executar

```bash
cd my-app
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Como testar

```bash
cd my-app
npm test
```
